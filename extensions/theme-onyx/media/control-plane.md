## Everything the agent does is observable

The Onyx Control Plane (`⌘⌃O`) shows:

- **Agent Activity** — every routing decision, model turn, and tool call, live, with reasons; pause, stop, or redirect mid-run
- **Context Budget** — exactly what fills the model's context window, token by token
- **Compute** — tok/s and time-to-first-token, the local equivalent of a cloud bill
- **Inspector** — replay any past run down to the exact wire prompt each turn sent
