# The first anchors campaign: kept, and in no analysis

This campaign ran before a defect in the campaign engine was found and fixed (`../2026-11-22-determinism/NOTES.md`): for up to a minute after a campaign checked out a task, prompts named the recently committed files of the task before. The two arms of a task run one after the other from one checkout, so the stale background fell on the arm that ran first, search and replace, and not evenly on both.

`PREREGISTRATION.md`, Amendment 4, written before any edit of this campaign had been read or scored, says what follows from that: the campaign is run again with the fix as `2026-11-22-anchors-2`, which is the sample of H-4 and whose edit calls enter H-3 and H-5. The records here enter no analysis. They are kept so that it can be checked that nothing was chosen by its result.
