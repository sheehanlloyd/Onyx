## Decisions made inside the item

- **Staleness is content, not version.** A save bumps nothing and a version can move without the text
  changing; the request stands while the file's text is what it was made from.
- **One proposal a file.** An inline edit on a file that already has changes waiting is refused rather than
  replacing them: `stageProposal` replaces, and the agent's hunks would be lost without a word.
- **Workspace files only.** The change set names files by workspace path. An inline edit in an untitled or
  outside file is refused with that reason. Before B9 it worked there, by writing straight into the buffer.
- **Escape during review discards what is left**, as the plan says of close. A reload is not a close: the
  proposal is in Onyx Changes afterwards.
- **The preview is a view zone**, not a second text model: read-only lines under the lines they would
  replace. C1 adds the diff editor.

## Not done here

- **The controller is not unit-tested.** Its widget, decorations and view zones need an editor; the
  end-to-end suite drives them. The rules it applies are the session's and the change set's, which are tested.
- **Two files of one inline request** do not exist: a request is one selection in one file.
