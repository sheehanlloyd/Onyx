## Decisions made inside the item

- **All or nothing.** The staging path already refused a call when any block failed; C3 keeps that and says
  which edit stopped it. A partly staged call would leave the model believing in edits that are not there.
- **Never both shapes.** A call with `search`/`replace` and `edits` is refused instead of guessing which was
  meant.
- **In order, against the running text.** The second edit is matched in the text the first one left. An
  edit whose quote an earlier edit of the same call changed is refused as not found.
- **The schema cannot say "one of two shapes"** in the subset Onyx validates (B12), so it requires `path`
  only and the tool checks the shape. An entry of `edits` must have both `search` and `replace`.

## Not done here

- **The generated episodes do not produce multi-edit calls.** Changing the generator changes every seeded
  episode and with it where each mutant is caught; the two scripted scenarios cover the shape instead.
- **No real-model measurement** of whether small models use `edits` well. That is a question for the lab
  (L4 can switch on it), not for this item.
