## What the new surfaces and the inline path found in the product

- **A note copied from the prompt's own context was shown as the model's words (D11).** The memory confirmation knew two sources, the request and tool results. A note whose text came from a note remembered earlier, or from the repository's playbook index, both of which every prompt carries, was shown as "the model wrote it". It now names those sources; `I-14/wrong-origin` checks it, and `D11-memory-unattributed` puts the gap back.
- **A one-shot request asked for 4,096 output tokens whatever the model's context (L1).** The inline edit, the commit message and the review go through `runOneShot`, which had a fixed cap; with a 4,096-token model that is the whole context before the prompt (`I-04/over-budget`, seed 1017 once the inline request ran in the rig). The model service now caps a request's output at what the context has left after its prompt.
- **A failed one-shot left a rejected promise unhandled (L1).** Fixed in `runOneShot`; the rig's test run reported it as an unexpected error.

## What is weaker than it reads

- **Ten of ten is "would be found if it came back".** At the baseline seven were found in the product; the three added here are found as mutants, with the actor or action each needed added to the rig.
- **The reviewing user was written for these findings.** It is a plausible user (edits while reviewing, types while an inline edit streams), drawn from its own random stream, but it exists because the three findings needed it.
- **The four D11 mutants are generic.** None is an audited defect except `D11-memory-unattributed`, which was the product until this follow-up. They show each surface's guard is exercised, not that a real regression of that shape is likely.
- **"Verified" for a clean file now rests on a language service being attached, not on it having run.** A language service that is attached and slow, or that does not report diagnostics for the file, still gives "verified" when nothing arrives.
- **The rig still has no child processes, no inline-edit widget and no language service.**
- **A5.3 did not make every run evict.** Half the runs of each policy answered after one read or fitted by shortening; the condition is a floor again.
- **A5.1's recommendation follows the rule, and the rule asks for both models.** For the 7B alone the data favour repaired text; that judgement is the owner's.
