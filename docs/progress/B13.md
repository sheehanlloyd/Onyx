## Decisions made inside the item

- **The numbers.** 15% of the context is left unused to absorb the error of estimating tokens from
  characters; the output cap is 15% of the context, between 256 and 4,096 tokens; the schemas cost what
  they serialize to. The 4,096 ceiling means a single reply is at most about 16,000 characters. L4 makes
  these a named configuration; they are constants in one object until then.
- **What an overflow teaches.** The plan says to halve the history and retry once. Halving a guess of the
  window can still leave the retried prompt too large when the guess was far off, so the observed context
  is set to the size of the request that was rejected, and the same planner makes the next request fit it:
  that drops at least 30% of what was just sent. One retry, then the runtime's message.
- **A request that cannot fit is refused, not sent.** When the instructions, the request and the schemas
  alone exceed the room, sending would violate the invariant and fail at the runtime anyway. The message
  gives both numbers.
- **2,048 tokens is refused for the eight-tool agent.** Measured: instructions and schemas are about 1,400
  estimated tokens, and 2,048 leaves 1,433 after the reply's share. The simulator's small profile was 2,048;
  it is 4,096 now, where one tool result fits at a time and every turn evicts. The four-tool read-only set
  does fit 2,048.
- **No marker is put into the prompt where calls were evicted.** The timeline says what was dropped; the
  model is not told. A marker might reduce repeated calls or might cause them; that is an L17 question, and
  this item does not guess.
- **The observed context only narrows.** It is kept per model on this machine and is not widened by
  requests that fit. L5 replaces it with a measurement.

## Limits, stated

- **A runtime that truncates silently is not detected here.** Ollama serves a model at its default context
  unless the model's parameters set `num_ctx`, and cuts a longer prompt without an error. Onyx then budgets
  against the architectural number, and the start of a long prompt can be lost at the runtime. L5's
  canary-recall probe measures the real number; this item provides the place it goes. SUPPORT.md says so.
- **`num_ctx` and `loaded_context_length` are read as the runtimes are understood to report them.** They were
  not checked against a live runtime in this item (none was running; L5 starts one and checks).
- **Estimates are estimates.** Code tokenizes worse than four characters a token; the unused 15% is the
  margin, and an overflow is handled when the margin is not enough.
- **The model library does not show the three numbers yet.** They are on the profile and in the diagnostics
  bundle; L5 puts measured and assumed values in the view.
