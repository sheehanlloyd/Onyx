## Decisions made inside the item

- **Two strengths of warning.** `git push origin main`, `npm install`, `npm test` and `python3 script.py`
  are everyday commands that do talk to the network or run code the prompt cannot show. Giving them the
  warning style would put a red triangle on most prompts and teach people to ignore it; saying nothing
  would repeat the defect. They get a plain "• looks like" line. The warning style is kept for destruction,
  privilege, remote code, persistence, uploads and raw connections. The labelled "everyday" set still
  scores 0 of 18 for the warning style.
- **Over-warning is kept and widened.** Quoted strings, comments and here-documents are classified as if
  they could run. `echo "sudo rm -rf /"` warns; so does `npm test # sudo rm -rf /`.
- **What cannot be read is said to be unread.** An unterminated quote or substitution produces a warning
  that the command could not be read completely, instead of a classification of the part that parsed.
- **The parser is a reader, not a shell.** No expansion, no aliases, no functions. `$CMD args` is a command
  whose executable is the text `$CMD`; nothing is inferred about it.
