## What measuring changes for the supported model

Before a model is measured its profile is what it was. After `Onyx: Measure This Model`:

- **Context goes from 32,768 to 4,096 tokens** for both pinned models on a default Ollama. That is what the
  server allocates; a longer prompt was being cut by the runtime without an error. The loop now fits the
  turn instead (B13). Runs evict earlier tool results sooner, and stop losing their instructions.
- **Constrained decoding stays on**, now for a measured reason: 0 of 5 native calls valid, schema enforced
  9 of 9.
- Nothing else in the profile moves.

The same context number is also read without a datasheet whenever the model is loaded (`/api/ps`).

## Decisions made inside the item

- **The probes talk to a transport.** The workbench, the script and the tests run the same suite; only the
  transport differs.
- **Enforced means every trial.** A schema that held eight times in nine is not one a parser may rely on.
- **Three trials or it decides nothing.**
- **A measured context only lowers the budget.**
- **Half a datasheet is not stored.** Cancelling stores nothing.
- **The measured tool-call number replaces the blended guess last**, so the existing rule that cuts a
  model's tool slots on observed parse failures is not triggered by a measured zero.

## Where this departs from the plan's wording

- **"Effective context by canary recall … bounded by the server-reported context."** Done as written, and
  the consequence is in the results: inside that bound the probe found no limit on either model. The profile
  then takes the server's allocation as the context. A probe that deliberately goes past the allocation, to
  see the cut happen, would be a stronger measurement and is not what the plan asked for.
- **"The datasheet is part of every scorecard (L11)."** L11 is a later module's.
- **Datasheets are not in the diagnostics export.**

## Found while doing this

- **The machine's power.** It was on a 13 W source and ran flat twice. The first real measurement, at 2%
  battery, gave 15 tokens a second for the 7B model and was discarded; the committed one was taken on the
  proper charger at 26% and matched three raw checks (48 to 50).
- **Verified against a live Ollama 0.33.0:** `/api/ps` carries `context_length`; `/api/tags` the digests;
  `/api/version` the version; `/v1/models` says `owned_by: library`. LM Studio's fields were not checked:
  it is not installed.
