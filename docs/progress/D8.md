The first soak and what it found (2026-11-24 and 25):
  The first soak (2026-11-24, from 17:13Z) was discarded: one suite run failed two checks, the next stood still for 62 minutes, and the Mac went onto battery and slept with the lid closed (18:21:28 to 18:26:59Z). Its output had been thrown away by the harness.
  Cause, reproduced on 2026-11-25: the suite's window was behind the owner's applications while the Mac was in use. A covered window stops animation frames, and the driver waits for a stable element before a click, so clicks timed out; a window without focus raised no inline completion and opened no inline edit; and the driver and the paste helper had no time limit, so one stalled call held a run with no output. With the window covered for four minutes by a full-screen window, the suite as it was aborted (`elementHandle.click: Timeout 30000ms exceeded`); with the fixes it passed every check under the same cover, and beside the soak's idle instance. Bringing another application forward without covering the window did not break the old suite: focus alone was not enough.
  Fixes: every driver call and the paste helper have a time limit and fail by name (15f571a060a); the workbench is launched with Chromium's switches against backgrounding covered windows, and focus emulation is turned on over CDP, with a check of both on every run (17a44401773); the soak keeps each run's log, stops a run after 20 minutes together with what it started, including the mock runtimes, and has a self-check with stand-in suites (`test/onyx/checks/soak-harness.test.mts`).
  What this does not change: a person typing into the test window would still change what the suite sees. The suite no longer needs the window in front; it does need nobody to use that window.
