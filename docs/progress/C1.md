## Decisions made inside the item

- **Code lenses and commands, both.** The plan names code lenses. A diff editor shows them only when
  `diffEditor.codeLens` is on, and its default is off; Onyx does not change an editor default that would
  put every extension's lenses into every diff. So the lenses are there for whoever has them on, and two
  commands accept or reject the hunk under the caret for everyone. The end-to-end check uses the command.
- **A caret on an unchanged line accepts nothing.** There is no "nearest hunk".
- **The proposal document is not the file.** It is a text model of its own under another scheme, and the left
  side of the diff is the file's ordinary model with the diff editor's default (not editable there).
- **When nothing is staged any more the document shows the file as it is**, so an open diff shows no
  difference instead of a proposal that no longer exists.

## Not done here

- **No mutant and no simulation coverage of the diff editor itself**: the rig has no editor area.
- **The first unit run of the whole suite after C1 took six minutes instead of sixteen seconds.** The cause

  connected); the mutants test alone took 10 seconds. Nothing in the tests changed.
