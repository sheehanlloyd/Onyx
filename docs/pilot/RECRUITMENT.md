**Subject: Two hours testing a local-model code editor, for people who already run local models**

I am looking for five to ten developers to try an experimental alpha of [name], an open-source code editor (a fork of Code - OSS) that runs coding models on your own Mac through Ollama.

You would be a good fit if you:

- have an Apple-silicon Mac with 16 GB or more (I especially need 16 GB and 48 GB machines);
- already run local models and know their limits;
- can spare about two hours once, and five minutes a week later.

What you would do: install a signed build, pull two small models, and do twelve short, fixed tasks in three small public repositories you have not seen (add a feature, fix a bug, answer a question about the code, and edit a file while the agent is working on it). You fill in a sheet as you go. Two of you, if willing, would repeat the tasks in Cline and in Zed so that I can compare.

What you should know first:

- It is an experimental alpha, and my own measurements of it are not flattering. With the two small models it is tested with, the agent rarely gets as far as proposing an edit on a real task. I am not asking you to be impressed. I am asking what happens when someone who is not me uses it, and above all whether it ever loses or changes your work without asking. That number has to be zero.
- Nothing leaves your machine unless you send it. The tasks are on public repositories. I will ask for your sheet and for a scorecard file the editor exports.
- I will not use your name without your written permission.
- There is no payment. You get the report, and credit if you want it.

If you are interested, reply with your Mac's model and memory and the local models you normally use.
