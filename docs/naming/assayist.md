# Assayist

Preliminary research, not legal clearance.

Date of all checks: 2026-11-22. Nothing was registered, reserved or purchased. Availability can change at any time.

**Verdict: DISQUALIFIED.** A same-name benchmarking orchestrator was published in 2026 and holds the crates.io name, and the word is a direct derivative of "Assay", which is saturated with AI evaluation tools. The same-name projects are small, so this is a judgment call; the GitHub handle and four domains were unclaimed.

## The name

Rare word for a person who assays (the usual form is "assayer"). Length: 8 letters. As a command and bundle name: `assayist`.

## Web search for collisions

Tool: web search (US index). Queries and results:

- Query: `"Assayist" software OR app OR AI OR developer tool`
  Result: Web search returned nothing named Assayist (nearest: an "Assay" SEO scoring tool, BioAssayBuddy, DevAssist). The GitHub and crates.io checks below found the collisions.

Web search alone missed several small projects during this research; the GitHub and registry lookups below are the stronger evidence.

Collisions found (all sources):

(1) crates.io "assayist", "Assayist orchestrator: run benchmark defs, capture, assemble AssayRuns, gate" (created 2026-07-20), from https://github.com/1stvamp/assayist , an eBPF benchmarking project (1 star, pushed 2026-08-21); (2) release-engineering/assayist, a build-composition analysis application: https://github.com/release-engineering/assayist (3 stars, last push 2022-12-08); (3) assayist.com registered 2026-04-30; (4) the whole "Assay" family of AI evaluation tools (see assay.md).

## Domains

Method: RDAP at the registry (Verisign for .com, Google Registry for .dev and .app, Identity Digital for .io and .sh) plus `dig +short NS <domain>`. HTTP 200 means registered; 404 means the registry has no record.

A 404 with no nameservers means the domain **appears unregistered**. It does not mean it is purchasable at standard price: premium pricing, reserved names and registrar holds are only visible at a registrar checkout, which was not started.
