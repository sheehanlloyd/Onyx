# Assay

Preliminary research, not legal clearance.

Date of all checks: 2026-11-22. Nothing was registered, reserved or purchased. Availability can change at any time.

**Verdict: DISQUALIFIED.** The name is already the common choice for LLM and agent evaluation tools; it cannot be made distinctive in this field.

## The name

To test the purity of a metal; any analytical test. Length: 5 letters. As a command and bundle name: `assay`.

## Web search for collisions

Tool: web search (US index). Queries and results:

- Query: `"Assay" AI developer tool OR LLM evaluation OR coding agent "assay"`
  Result: Several AI tools share the name: assay-core, "High-performance evaluation framework for LLM agents" (https://docs.rs/crate/assay-core/3.29.0, https://pypi.org/project/assay-it/0.9.0/); assay-ai, signed evidence for AI workflows (https://pypi.org/project/assay-ai/1.18.0/); Assay adversarial AI code verification (https://www.indiehackers.com/product/assay); assay.tools agent-friendliness ratings (https://github.com/assay-tools/assay); Assay.js LLM testing library (https://assay.js.org/guide/why-assay.html).

Web search alone missed several small projects during this research; the GitHub and registry lookups below are the stronger evidence.

Collisions found (all sources):

Direct and numerous: at least five AI evaluation or verification tools named Assay (URLs above), plus crates.io "assay" (Rust testing macro, 81009 downloads), npm "assay" and PyPI "assay" (testing libraries).

## Domains

Method: RDAP at the registry (Verisign for .com, Google Registry for .dev and .app, Identity Digital for .io and .sh) plus `dig +short NS <domain>`. HTTP 200 means registered; 404 means the registry has no record.
