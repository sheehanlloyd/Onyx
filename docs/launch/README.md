Rules these drafts follow, and that an edit must keep:

- No "from scratch": it is a fork of Code - OSS and says so in the opening lines.
- No novelty words. None has been approved (DEC-09), and `docs/research/RELATED.md` shows close prior work for every technique.
- No feature montage and no predictions about stars or adoption.
- Every number links to the file that produces it. If a number changes in `docs/research/data/numbers.json`, change it here.
- The unflattering result is the lead, not a footnote. A reader who installs this after a flattering post and finds that a 7B model proposes nothing will be right to feel misled.
- Links assume the repository's current name. The product is due to be renamed; redo the links and the name after the rename, and add "formerly Onyx" only then.
- Nothing is posted before the signed release exists. A post that links to a download macOS refuses is worse than no post.
